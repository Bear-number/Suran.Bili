# Suran.Bili

B 站（bilibili）的查询与互动：视频、搜索、热榜、评论弹幕、UP 主与动态、个人数据，以及直播分区与开播状态。写操作默认关闭。

## 功能

- 视频详情与分 P、关键词搜索（按播放 / 收藏 / 最新排）、热门、相关推荐
- UP 主资料与粉丝数、作品列表
- 评论区与楼中楼、弹幕全文与高频词
- 扫码登录后读收藏夹、稍后再看、历史记录、关注列表
- 动态：列表、详情、发布、删除、点赞
- 写操作（默认关，需确认）：点赞、投币、收藏、关注、回评论、发弹幕
- 直播：分区树、各大区在线人气榜、大区人气一览、单房间开播与信息
- 环境自检：检查登录态与接口可用性
